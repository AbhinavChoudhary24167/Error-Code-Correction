## Validation boundary

The exact logical equations and software behaviors are testable now. Physical
PPA, foundry-specific embodied carbon, the original 189-scenario claim, and the
submission PDF are not. Completing those rows requires (1) the authoritative
paper/thesis sources and bibliography; (2) a documented standard-cell library
and synthesis/STA flow or existing reports; and (3) the original scenario
generator/data. Supplying these artifacts should trigger a new evidence run,
not an extrapolation of the current projected constants.
