# GREEN Matrix 3.1 physical population

This directory is an additive evidence adapter over the frozen GREEN Matrix
3.0 foundation.  It populates v3.1 records only from repository evidence whose
hashes and original qualification boundaries are retained.

The campaign adds five matched upstream-original OpenROAD observations for each
of U0 and E0, eight matched deterministic RTL workload traces, a seed-11
partial-annotation post-route power/energy diagnostic, RTL latency and
initiation-interval semantics, macro-level physical organization, an explicit
two-stage reliability bridge, and a technology-mismatch literature registry.

It does **not** establish E5 energy, a bitcell coordinate map, Qcrit, a SKY130
physical event rate, physical SDC/DUE/FIT, a routed nontrivial interleaver,
manufacturing carbon, CSCI, MRCC, or a global winner.

See `FINAL_REPORT.md` for the scientific outcome and `REPRODUCE.md` for the
deterministic build.
