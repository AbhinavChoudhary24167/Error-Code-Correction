# Activity-qualified ECC energy evidence

This additive package asks whether ECC architecture energy ordering remains valid
when vectorless power is replaced by operation-specific switching activity while
physical implementation, timing qualification, and parasitic identity are held
fixed.

The primary evidence is the sealed five-seed matched Hamming/Hsiao campaign at a
10 ns target period. Run `python scripts/build_artifacts.py` to verify the sealed
inputs and regenerate derived data, tables, and figures.

Publication sources, submission PDFs, and review-only material are intentionally
excluded from this repository. The retained `data/`, `figures/`, `tables/`,
`FINAL_REPORT.md`, and provenance files are the reusable evidence record.

No file outside this directory is modified by the package.
