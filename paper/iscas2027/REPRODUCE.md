# Reproducing the ISCAS 2027 Paper

## Reproduction boundary

These instructions reproduce the paper's derived values, figures, tables, and
PDF from frozen repository evidence. They do **not** rerun OpenRAM or the
RTL-to-GDS campaigns. Heavy campaign regeneration is intentionally outside the
default paper build.

Run all commands from `paper/iscas2027/`.

## 1. Generate values, provenance, tables, and figures

```powershell
python scripts\build_artifacts.py
```

Expected cohort summary:

```text
primary_seeds=[13, 17, 19, 23]
primary_records=40
hsiao_lower=4/20
```

The script reads only these authoritative inputs:

- `campaigns/iscas_sustainability_extension/green_v3_2_matched_openram_orfs_validation/PHYSICAL_RUN_RESULTS.csv`
- `campaigns/iscas_sustainability_extension/green_v3_2_matched_openram_orfs_validation/ARCHITECTURE_AUDIT.json`
- `campaigns/iscas_sustainability_extension/green_v3_3_activity_complete_e5/GREEN_V3_3_ADDITIVE_MATRIX.json`
- `campaigns/iscas_sustainability_extension/green_v3_3_activity_complete_e5/CAMPAIGN_STATUS.json`
- `campaigns/iscas_sustainability_extension/green_v3_3_activity_complete_e5/RUN_MANIFEST.json`
- `campaigns/iscas_sustainability_extension/green_v3_3_activity_complete_e5/WORKLOAD_MANIFEST.json`

The exact current SHA-256 values are emitted into `RESULT_PROVENANCE.csv` and
`tables/derived_metrics.json`.

## 2. Compile the manuscript

```powershell
pdflatex -interaction=nonstopmode -halt-on-error main.tex
bibtex main
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```

The final output is `main.pdf`. The expected format is US Letter, five pages
total, with pages 1--4 technical content and page 5 references only.

## 3. Validate the artifact

```powershell
python scripts\validate_artifacts.py
pdfinfo main.pdf
pdffonts main.pdf
```

Validation should report five pages, no unresolved citations/references, no
overfull boxes, and no provenance hash drift. Every font listed by `pdffonts`
must show `emb=yes`; no Type 3 font is permitted.

## 4. Repository regression suite

From the repository root, run the commands required by `AGENTS.md`:

```powershell
make
make test
python3 -m pytest -q
```

If `python3` resolves to a distribution without the repository dependencies,
record that environment failure and additionally run the same suite using the
working Python interpreter. Do not alter campaign evidence to make a test pass.

Observed on 2026-09-10 in the supplied dirty worktree: `make` passed;
`make test` completed with 482 passes and two Gate03 scope-allowlist failures;
`python3 -m pytest -q` completed with 718 passes and five failures (the same two
scope checks plus three frozen-campaign/hash checks). See
`SUBMISSION_READINESS.md`. These failures predate or are structurally unrelated
to the paper validator; they must not be hidden by deleting user campaign work.
