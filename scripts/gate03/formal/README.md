# BCH exact-equivalence entry contract

No BCH candidate is accepted in Gate 03. A future Gate-03R candidate may enter only after:

1. encoder formal equivalence to the frozen Gate-02 generator transform, or formal linearity plus exact agreement for zero and all 64 basis messages; and
2. decoder proof with symbolic payload data for all 3,082 weight-0/1/2 masks, covering decoded data, corrected codeword, latency, and status semantics.

This directory intentionally contains no translated, generated, repaired, or substitute BCH RTL. Probe-only campaigns—including 54 probes—are incomplete.
