## Detailed generated documentation

The generated [ECC catalogue](ECC_CATALOGUE.md), [verification methodology](VERIFICATION_METHODOLOGY.md), [CLI reference](CLI_REFERENCE.md), [claim ledger](CLAIM_LEDGER.md), and [results interpretation](RESULTS_AND_INTERPRETATION.md) are regenerated by `python scripts/build_documentation.py`. They describe the registry-centred software study. Campaign-specific status files under `campaigns/` supersede that study only inside their explicitly declared physical or activity evidence boundaries.

Run `make docs-check` to validate links in the public layer. Run `make reproduce` only when intentionally regenerating the established registry study and generated documentation.
