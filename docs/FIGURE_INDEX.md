## Interpretation rules

- Null values appear as “not characterized,” never zero.
- Rejected candidates remain visible in audit plots but are removed before Pareto selection.
- Categorical winner heatmaps show computed grid cells or explicitly labelled modal aggregates; no interpolation occurs.
- Logarithmic axes are used only for positive probability scales and labelled as probabilities.
- Structural depth is never labelled measured latency; operational carbon is never labelled total carbon when embodied data is absent.
- Figure captions and alt text live both in this index and in the documentation page that includes the image.
