# Roadmap

This roadmap records evidence gaps, not delivery promises.

## Highest scientific priorities

1. Complete and validate a fresh 256×72 macro package with LEF, Liberty, Verilog, SPICE, DRC, LVS, and characterization under a new campaign identity.
2. Measure or otherwise qualify macro-internal activity/energy for the same operations as the E5 ECC-logic records.
3. Establish a verified physical bitcell-to-logical mapping and event-footprint population for SDC/DUE/FIT and interleaving claims.
4. Add measured or independently calibrated Qcrit/radiation evidence with uncertainty.
5. Obtain a SKY130-applicable manufacturing/lifecycle inventory, yield/allocation model, and clearly bounded functional unit.
6. Expand matched seeds, PVT corners, workloads, capacities, and implementation variants with preregistered sampling/statistical analysis.

## Artifact engineering priorities

- exercise the reviewer smoke target continuously on supported platforms;
- publish release archives and immutable checksums for accepted campaign packages;
- consider Git LFS or an archival DOI for large GDS/log evidence without rewriting current history casually;
- reduce historical environment coupling in new controllers while retaining old executed paths;
- add schema-level validation for every campaign and compatibility migrations for legacy records.

A global ranking should be considered only after the required reliability, complete memory energy, and lifecycle operands are jointly qualified. Until then the correct result remains `NO_GLOBAL_WINNER_QUALIFIED`.
