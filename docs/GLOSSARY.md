# Glossary

| Term | Meaning in this repository |
|---|---|
| ECC | Error-correcting code |
| U0 | Matched unprotected baseline |
| SECDED | Single-error correction, double-error detection under a declared implementation/universe |
| Hsiao SECDED | SECDED construction using odd-weight parity-check columns |
| SEC-DAEC | Declared single-error/double-adjacent-error correction policy; the matched candidate failed its functional gate |
| BCH | Bose–Chaudhuri–Hocquenghem code; parameters and decoder policy must be stated |
| SBU/DBU/MBU | Single-, double-, and multi-bit upset/error classes |
| SDC | Silent data corruption |
| DUE | Detected unrecoverable/uncorrectable error |
| SER | Soft-error rate |
| FIT | Failures per billion device-hours |
| Qcrit | Critical collected charge that produces an upset; model input here, not a qualified measurement |
| PVT | Process, voltage, and temperature condition |
| ORFS | OpenROAD-flow-scripts |
| OpenRAM | Open-source SRAM compiler |
| DRC/LVS | Design-rule check / layout-versus-schematic check |
| E0–E7 | Evidence tiers from absent through silicon/fab measurement; see [Evidence model](evidence-model.md) |
| E5 | Activity-qualified post-route evidence for a bound measurement boundary |
| `M_E` | Evidence/qualification matrix |
| `M_P` | Physical implementation matrix |
| `M_S` | Scenario/sustainability translation matrix |
| Functional unit | The normalized service being compared, such as useful payload capacity and operations |
| Pareto front | Eligible non-dominated alternatives for declared objectives/directions |
| Provenance seal | Hash/identity record for an immutable evidence package |
| Qualified | Permitted for a specific metric and use after all gates; not a universal property of a file |
