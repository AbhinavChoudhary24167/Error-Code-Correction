# Pre-rebuild documentation archive

This directory preserves the documentation state that existed immediately
before the GREEN-ECC-PHY documentation rebuild on 2026-08-04. The repository
was clean at the recorded baseline (`227e73e`), so these files are committed
historical material rather than rescued uncommitted changes.

The archive is evidence of documentation history only. It is not a source of
scientific truth for the rebuilt documentation. Current claims must be traced
to executable source, schemas and manifests, tests, or freshly regenerated
machine-readable artifacts, in that order.

The `docs/` subdirectory mirrors the prior `docs/` tree. Prior root-level
guides and reports are preserved alongside it.
